# The hackathon record, September 2026

Everything in this folder was written for the judges of the Agentforce for
Good Hackathon (Dreamforce 2026), where Curb Cut took first place in the
Builder Track. It is kept as a dated record, not as current documentation.

The demo org, the judge credentials, the phone number and the invite links
these documents mention belonged to the hackathon deployment and are retired.
For installing and running Curb Cut today, start at the repository README and
DEPLOY.md.

- JUDGE-TEST-GUIDE.md — how judges tested every channel, end to end
- JUDGE-COMPANION.md — what every press did, and where it landed
- ACCESSIBILITY-REFLECTION.md, RAI-REFLECTION.md, OBSERVABILITY-REFLECTION.md —
  the organisers' three reflection prompts, run over the submitted system
- SCREEN-READER-WALK.md — a scripted screen reader walk of the submitted ask page
- Curb-Cut.pptx, curb-cut-demo.srt, images/, screenshots/ — the deck, captions
  and stills as submitted
