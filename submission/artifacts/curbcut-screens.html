Seven screens, every word real.

Not one string here was invented for the picture. Every line of copy was captured from the deployed org, which is why the mockups are worth looking at.

These are vector, not screenshots. Every label is live text, so any of them opens in Figma, Illustrator or a text editor and can be recoloured, retyped or pulled apart without going soft at the edges. The source files sit in submission/devpost/mockups/.

The first screen

No account, no login, nothing written down yet. The four steps are named up front so nobody is walking into an unknown process, and the starters exist because typing is the hard part for some of the people who arrive here.

Real options, sourced

Every row is a real library entry with its cost and its citation. The agent may only name what this action returned, it cannot improvise an accommodation, invent a cost, or invent a precedent count.

The hedge is not agreement

The interesting case is not refusal. It is what somebody actually says when they are unsure and being agreeable. Two independent locks hold this: the Apex refuses without approval passed through, and a validation rule blocks the insert without it.

Six characters, shown once

There is no account, no password and no number on record, so there is nothing to look somebody up by. They hold the code; the system holds a hash it cannot reverse. The alphabet omits O 0 I 1 S 5, an accessibility decision inside a cryptographic one.

The same words on a phone

HUMAN books a real handoff to a named person. OFF with the code withdraws a disclosure that was set on a web page months earlier. Text is awaiting carrier registration; voice on the same number needs none and works today.

Slack is the employer’s estate

Workspace owners can export direct messages on most plans. So this is said first, before anything else is discussed, and Slack never drafts, never sends, and never answers in a channel.

The refusal

An operator is asked for a diagnosis by their own manager. The request does not hit a locked field, it hits nothing. And the answer hands the operator the sentence to say upward, so refusing costs them nothing either.
