Getting help and opting out

Reply HELP at any time for help and contact details.

Reply STOP at any time to stop receiving messages from this number. You will receive one confirmation, and then nothing further. You can rejoin later by texting the number again.

Four other words do something different. None of them stops the messages, and they work the same way on every channel, text, email, Slack or the web page:

  • HUMAN, a real person takes over, on the channel you are already using. You will not have to explain it again, and nobody will ring you.
  • OFF, turn off a standing preference you previously saved. Immediate, and you will not be asked why. Send it with the six-character code you were given when you saved it, like OFF 4KQ7MT. We hold no account and no number for you, so the code is the only way to find it.
  • DELETE, discard a drafted request before it is sent. This one only means something while a draft is open.
  • WHO, see everyone who has been shown a standing preference of yours.

What we promise

  • Nothing is sent to your employer without your explicit yes in the conversation. A hedge is not a yes. If you say "I guess so," the assistant will ask again rather than send.
  • We never ask what condition you have, and there is nowhere in the system built to store one. If you mention it anyway, it is taken out of the text before anything is saved, and you are told so in the same reply. That removal runs against a list of conditions we recognise, and no list covers every word in every language, it is a real safeguard rather than a guarantee, and you should know which.
  • We never route you to a phone call. If you need a person, you get one by message.
  • We only describe adjustments from a sourced library. If we do not know, we say so rather than guess.
