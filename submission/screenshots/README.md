# Screenshots

Every one of these is a capture of the deployed site or console, taken by
driving a real browser through the real flow. None is a mock-up, and the words
on them are what the deployed system said. Downscaled to 1600 wide for the
Devpost gallery; the 3200-wide originals are reproducible with `node video/pages.mjs`
and `node video/flow.mjs`.
