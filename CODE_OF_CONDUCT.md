# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Two things worth saying in our own words:

- This is a project by and about disabled workers. Talk about disability the
  way you would with a disabled colleague in the room, because they are.
  Identity-first and person-first language are both welcome; policing either
  is not. Nobody here owes anyone their diagnosis, and nobody's access need
  requires justification.
- Assume the person asking a basic question is using a screen reader, a
  translation tool, or their third language. Answer the question.

Reports go to **curbcut@havihi.digital** and are read by the maintainer.
Enforcement follows the Covenant's ladder.
